# GW3Decomp
This is the entire source code for Geometry Wars 3: Dimensions Evolved. This contains the entire mode functionality (waves, pacifist, etc) as well as the super states and much more.

All these files are in luac format, which require [unluac](https://sourceforge.net/projects/unluac/files/latest/download). If you would rather prefer a lua version, let me know.
